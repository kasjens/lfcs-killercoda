# Repair

Repeat only the items you did not produce cold. Not the whole set again —
re-running things you already know measures this morning, not September.

```
drill --review
```{{exec}}

If the last round was clean this will say so and exit, which counts as passing
this step.

### What to do with the number

The topic breakdown at the end of a round is the useful output, not the
percentage. It sorts weakest first and marks anything under 70%.

- **SECTIONS weak** — cheapest to fix. It is a table, and it is the same table
  every time.
- **PAGER weak** — fix this one first regardless of the score. It is the topic
  that actually buys you minutes in the exam, and there are only eight items.
- **EXAM-LOOKUPS weak** — you know the tools but not where their documentation
  lives. Read `man 7 systemd.directives` and `man -k firewalld` once each.

Then run it again in a few days, not today. A second pass on the same afternoon
measures short-term memory.
